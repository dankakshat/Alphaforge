# AlphaForge

A local-first quantitative research workstation for discovering, testing, and ranking multi-asset trading signals.

## Run

Open `outputs/AlphaForge.html` in any modern browser. No install or build step is required.

## Included workflows

- Automated signal-template discovery across momentum, mean-reversion, breakout, volatility, and volume families
- Long-only and long-short experiment controls, daily and intraday bar selection, and transaction-cost assumptions
- Candidate leaderboard ranked by deflated Sharpe ratio and robustness
- Interactive candidate inspection, equity curve, factor attribution, saved research, and report export
- Polygon.io key configuration with a deterministic local fallback panel
- Thesis-to-signal-idea workflow designed for an optional OpenAI integration

> AlphaForge is a research simulation tool only and does not place trades or provide investment advice.
